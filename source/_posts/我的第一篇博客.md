一直以来，我都想建立一个属于自己的网站。我是一个业余编程爱好者，会一点 Python，最近在学 C++ 和 JavaScript，对网络安全和 AI 也很感兴趣。虽然还没想好这个网站最终要分享什么，但“有一个自己的网址”这件事本身，就足够酷了。

在这篇文章里，我将记录我如何用完全免费的方式，把本地电脑上的一个文件夹，变成了互联网上一个真实的网站，以及在这个过程中我搞明白的几个核心概念。首先我得声明，我是在deepseek老师帮助下完成这个工作的，本文也是分享性质，如果能对你有所帮助，那真让我高兴！

## 搭建网站，我用了哪些工具？

一开始我以为建站要写一堆复杂的代码，或者去买昂贵的服务器。但实际上，现代的开源工具让我只敲了几行命令就搞定了。我主要用到了四个东西：

### 1. Node.js 是什么？
Node.js 简单来说，就是一个能让 JavaScript 脱离浏览器，直接在电脑上运行的环境。
为什么建站需要它？因为我用的博客框架（Hexo）是用 JavaScript 写的，必须依赖 Node.js 才能在我的电脑上跑起来。你可以把它理解为一个“发动机”，没有它，博客这台车就跑不动。

### 2. Hexo 是什么？
Hexo 是一个快速、简洁且高效的**静态博客框架**。
以前建站，可能需要安装 WordPress 这种需要数据库的“动态系统”。而 Hexo 的本职工作，是把我们写好的 Markdown 格式的文章（比如现在你看到的这篇），自动转换成一堆现成的 HTML、CSS 网页文件。
**它的好处是：** 纯静态网页，加载极快，而且不需要买服务器和数据库。

### 3. Git 是什么？
Git 是一个**版本控制系统**。最开始我以为它只是个上传代码的工具，其实不是。
在本地电脑上，`git init` 创建了一个仓库，之后的每一次 `commit`（提交），都相当于给代码拍了一张“快照”。如果以后我把博客改坏了，随时可以用 Git 恢复到之前的某个快照。
而 `git push`，则是把本地这些保存好的文件，打包发送到远程的代码托管平台（我用的是 GitHub）。这就好比本地是草稿箱，GitHub 是云端的存档柜。

### 4. Vercel 是什么？
Vercel 是一个**静态网站托管平台**。
前面说到，Hexo 把文章变成了静态网页文件，Git 把这些文件传到了 GitHub。但 GitHub 上的文件是代码形态的，无法直接变成一个好看的网页让任何人访问。
这时候 Vercel 登场了。它就像一个全自动的工厂，它读取 GitHub 上的代码，自动运行 Hexo 进行生成，然后把生成的网页发布到全球的网络上。
**最关键的是：免费、自动配置 HTTPS 安全证书、而且每次我把新文章推送到 GitHub，Vercel 都会自动重新发布网站。**

## 我的操作流程

搞懂了这些，整个流程就清晰了：

1. 用 `hexo init` 生成博客骨架。
2. 在本地写文章。
3. 用 `git commit` 保存记录，用 `git push` 推送到 GitHub 仓库。
4. Vercel 自动同步 GitHub 的代码并发布到公网。

## 遇到的真实问题记录

在操作过程中，我遇到了一个因为网络环境导致的 SSL 报错。本地 Git 在推送到 GitHub 时提示无法验证证书。我通过临时关闭 SSL 验证（`git config --global http.sslVerify false`）解决了问题，让代码先传上去。之后可以再尝试用系统证书库（`http.sslBackend schannel`）来恢复安全验证。

另外，Vercel 免费提供的默认域名（`*.vercel.app`）在国内网络环境下通常无法直连访问，需要借助代理。后续我会考虑买一个自己的专属域名绑上去，以便让国内的朋友也能顺畅访问。
